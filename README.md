# Finanças Pessoais

Aplicação web de inteligência financeira pessoal para consolidar extratos bancários e faturas, distinguir movimentação financeira de realidade econômica e acompanhar receitas, gastos pessoais, terceiros, histórico e compromissos conhecidos.

## Estado atual

O projeto está na transição de Discovery para implementação. Ainda não há aplicação inicializada.

Documentos principais:

- `MASTER_SPEC.md`: fonte de verdade funcional e técnica da V1.
- `CODEX.md`: instruções operacionais para implementação com o Codex.
- `AGENTS.md`: instruções carregadas automaticamente pelo Codex.

## Stack definida

- Next.js
- TypeScript
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage

As funcionalidades essenciais da V1 devem operar em free tiers e não podem depender de uma API paga.
